PANDUAN SINGKAT

Cara menggunakan

  1. Jalankan halaman lewat VS Code Live Server atau localhost.
  2. Tekan Aktifkan kamera dan izinkan akses kamera.
  3. Pastikan tangan terlihat jelas dengan pencahayaan yang cukup.
  4. Ketika titik tangan terdeteksi, aplikasi akan menampilkan status pelacakan.
  5. Tombol suara hanya membacakan pemberitahuan prototype, bukan hasil terjemahan BISINDO.

Untuk menjadi penerjemah BISINDO, tahap berikutnya adalah memasang model yang dilatih dan dievaluasi dengan data isyarat BISINDO yang benar.
